# website-react

Personal portfolio & links site ([nnt25.net](https://nnt25.net/)). Built with React 19, Vite, and Cloudflare.

## Development

```bash
# Install dependencies
npm install

# Local development
npm run dev

# Build production bundle
npm run build

# Deploy to Cloudflare
npm run deploy
```
